## 📖 Overview

**FitFlex Gym** is a static, single-page marketing website for a fitness center based in Ranchi, Jharkhand. It is designed to convert visitors into members by clearly showcasing the gym's offerings, pricing tiers, and social proof — all on one smooth-scrolling page.

The site is built **without frameworks or build tools**, making it lightweight, fast, and trivially deployable to any static host like GitHub Pages, Netlify, or Vercel.

## ✨ Features

- **Fully responsive** layout — adapts from large desktop screens down to mobile.
- **Sticky navigation bar** with in-page anchor links for smooth jumping between sections.
- **Hero section** with a strong call-to-action ("Join Now" / "Learn More").
- **Facilities showcase** — Strength Training Zone, Cardio Theater, and Group Fitness Studio with imagery.
- **Services grid** — Personal Training, Nutrition Counseling, Fitness Assessment, Group Classes.
- **Three-tier membership pricing** (Basic / Premium / Elite) with a highlighted "Most Popular" plan.
- **Testimonials section** featuring real member success stories with photos and roles.
- **Contact section** with location, phone, email, opening hours, an embedded Google Map, and a message form.
- **Footer** with quick links, contact info, and a newsletter subscription box.

## 🚀 Getting Started

No dependencies or build step needed — just a browser.

### Option 1 — Open directly

```bash
git clone https://github.com/nikhilrana2715/FitFlex-Gym.git
cd FitFlex-Gym
start index.html      # Windows
open index.html       # macOS
xdg-open index.html   # Linux
```

### Option 2 — Local server (recommended)

```bash
# Python 3
python -m http.server 8000

# OR Node.js
npx serve
```

Then open `http://localhost:8000`.

## 🎨 Customization

- **Colors / Theme** → edit the variables or root styles in `style.css`.
- **Text / Content** → update the relevant sections in `index.html`.
- **Pricing** → change amounts and feature lists in the Membership section.
- **Images** → swap the Unsplash URLs (or local image paths) in the markup.
- **Map** → replace the Google Maps embed `iframe` `src` with your own location.

## 🌍 Deployment

### GitHub Pages
1. Push the project to a GitHub repository.
2. Go to **Settings → Pages**.
3. Set *Source* to the `main` branch, `/root` folder.
4. Save — live at `https://<username>.github.io/<repo-name>/`.

### Netlify / Vercel
Drag-and-drop the folder into Netlify, or connect the repo to Vercel — no build command needed for a static site.
